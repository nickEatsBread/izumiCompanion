You’re almost there.

One last setting lets future Companion updates run without your computer.

  1. On the TV, open Apps → 12345.
  2. Set Developer Mode Host PC IP to 127.0.0.1.
  3. Hold the remote’s Power button for at least 5 seconds to restart. If the TV stays off, press Power again.
  4. Open izumi companion from Apps.

To use this installer again, set Host PC IP back to this computer and repeat the restart above.

Open izumi companion from TV Apps and pair it with your izumi device.
