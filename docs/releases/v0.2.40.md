# izumi Companion v0.2.40

- Releasing fast-forward or rewind immediately shows buffering progress. A stalled seek reconnects at the requested position instead of leaving an indefinitely frozen frame.
- Adaptive playback requests the highest allowed quality after a seek. The loading display has a larger spinner and text, clear spacing, and a readable progress meter.
- The timeline shows confirmed buffered ranges and clears the previous range when seeking. It no longer invents downloaded video ahead of the current position.
- Check for updates shortly after TV startup, retry interrupted network checks, and offer a dismissed update again on the next launch.
- Cancel superseded searches, reuse recent results, and keep skeletons visible while the current query is loading. Matching title suggestions appear beneath the search field and support remote navigation.
- Enable both Samsung voice services. Recognized “search <title>” and bare-title speech opens catalogue search from any screen; older firmware also receives registered title commands.
- Make home tile artwork and title changes immediate, reduce repeated artwork decoding, and apply remote focus before painting.

Samsung exposes progress toward its playback buffer, but not a complete downloaded-video range. Older voice services recognize registered commands rather than unrestricted dictation. Picture quality and microphone recognition still depend on the selected video and TV firmware.

All release packages use version 0.2.40. Update through izumi Updater or install from this release. This release is verified with automated tests and the Chromium 56 browser runtime; physical-TV playback and microphone verification remain to be performed.
