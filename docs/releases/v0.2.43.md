# izumi Companion v0.2.43

- Add **Update Worker** to Settings for TVs connected to a Cloudflare Worker. Check the installed Worker version and use the on-screen guide or QR code to finish updating from the main izumi client.
- Improve TV browsing and title presentation, with smoother navigation and more reliable remote focus.
- Restore cloud playback choices and improve subtitle delivery and preferred-track selection.
- Add more flexible screen layouts while preserving saved TV connections and update identities.

Companion, the TV updater, desktop installers, and mobile installers all use version 0.2.43. Update through izumi Updater or install from this release. The iOS installer is unsigned and requires signing before installation.
