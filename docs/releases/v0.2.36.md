# izumi Companion 0.2.36

Adds an update prompt to Companion and the separate izumi Updater TV app.
The helper verifies the release, signs it for the TV, reports download and
installation progress, and returns to Companion when Update now was selected
inside Companion. Opening the helper directly lets you check and update manually.

The update popup and TV helper use the izumi wordmark, charcoal surfaces,
white controls and aqua accents, with readable setup codes and progress states.

The helper requires one-time setup from the desktop tooling and Tizen 3.0+ Web
service support. After encrypted identity setup, set Developer Mode Host PC IP
to `127.0.0.1` and restart the TV. Existing pairing and playback data are retained
by updating the same application identity.

Release assets:

- `izumi-companion.wgt` — Companion application, version 0.2.36.
- `izumi-updater.wgt` — separate TV updater, version 0.2.36.
- Desktop installers for Windows, macOS (Apple Silicon and Intel), and Linux.
- `SHA256SUMS` — checksums for all release packages.

Both public WGTs are unsigned and contain no TV signing identity. The desktop
installer downloads the release packages and signs them for the connected TV.
Future Companion updates use the same author identity and preserve pairing data.

This is the first public updater release. End-to-end hardware validation is in
progress; retain the desktop installer and the original signing-identity backup
for recovery. Drafts and prereleases are excluded from automatic update checks.
