# izumi Companion 0.2.36

Adds an update prompt to Companion and the separate izumi Updater TV app.
The helper verifies the release, signs it for the TV, reports download and
installation progress, and returns to Companion when Update now was selected
inside Companion. Opening the helper directly lets you check and update manually.

The helper requires one-time setup from the desktop tooling and Tizen 3.0+ Web
service support. After encrypted identity setup, set Developer Mode Host PC IP
to `127.0.0.1` and restart the TV. Existing pairing and playback data are retained
by updating the same application identity.

Release assets:

- `izumi-companion.wgt` — version 0.2.36; leave the test TV at 0.2.35 so the
  updater installs this package during the test.
- `izumi-updater.wgt` — version 0.2.36; deploy this helper directly for setup.

Both public WGTs are unsigned and contain no TV signing identity. Desktop
installer source and binaries are awaiting review and are excluded from this
release. The full physical-TV upgrade remains unverified until provisioning,
loopback setup and a complete newer-version install have been exercised.

This release is prepared locally. Push and GitHub publication are on hold for
review. The updater cannot discover it while it is unpublished or a draft.
