# Companion 0.2.45

- Request private Worker updates directly from the TV after one-time Cloudflare setup.
- Show automatic-update status and distinguish queued builds from installed versions.
- Check pending installations while the update screen is open and cancel the status request on exit.
- Guide older or unconfigured Workers through enabling automatic updates.
- Refresh the shared installer Worker snapshot to 1.12.0 for fresh TV setups.

Requires Worker 1.12.0 for the update endpoint. The Worker checks stable releases every six hours
independently of the TV. Its deployment hook remains private; the TV uses its existing pairing
credential and never receives Cloudflare deployment credentials.

Local verification: Companion type checking and 331 tests, 19 updater tests, production builds,
and widget packaging. Publishing and physical-TV verification remain pending.
