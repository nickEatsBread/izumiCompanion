# izumi Companion 0.2.49

- Sources now appear progressively while the private Worker is still searching. Press Back to choose an available source immediately.
- The resolve channel can ask the TV to fetch supported public source metadata during the same lookup.
- Brief connection drops resume the existing lookup. Older Workers and TVs retain the HTTP fallback.
- Source identities remain stable when later results change their order, and cancellation prevents late results from taking over playback.
- Desktop and mobile installers include Worker 1.14.0 and provision its SQLite Durable Object binding.

Live search is unchanged. This release targets source resolution first.
