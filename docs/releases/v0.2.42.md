# izumi Companion v0.2.42

- Preserve the v0.2.41 playback, buffering, search, voice-command, startup-update, and home-navigation improvements in the combined release history.
- Add connected-account catalogues to the TV catalogue picker, including nested folders and additional-page loading.
- Allow a TV to restore its saved connection to a phone or desktop directly from Settings.
- Keep independent TV catalogue requests on the private Worker when no linked device is available, with clear retry handling when catalogue loading fails.
- Include the matching Worker migrations and installer support needed by the new catalogue and connection flows.

All Companion, updater, desktop-installer, and mobile-installer packages use version 0.2.42. Update through izumi Updater or install from this release. The combined history is verified with automated tests and the Chromium 56 browser runtime; physical-TV playback and microphone verification remain to be performed.
