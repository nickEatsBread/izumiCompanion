# izumi Companion v0.2.47

- Include Worker 1.13.1 from the main Izumi repository, incorporating the resolver changes merged in [#60](https://github.com/nickEatsBread/izumi/pull/60).
- Refine TV source results using title, year, and runtime evidence before ranking, while retaining available choices when metadata is incomplete.
- Preserve valid configured sources during profile sync and support up to 16 source entries.
- Keep the TV app, updater, and desktop/mobile installers aligned at v0.2.47.

The resolver changes run in Worker 1.13.1, which is included in the installers and available through the automatic Worker update channel.
