# izumi Companion v0.2.38

Fixes recovery after standalone Cloudflare TV setup:

- Opens the configured home catalogue instead of explicitly selecting AniList when multiple homes are enabled.
- Shows Cloudflare/provider and malformed-response errors on the setup screen, even when Samsung's receiver service is connected.
- Adds Retry catalogue without discarding saved Worker credentials or repeating account creation.
- Regenerates the catalogue after a restart when no encrypted desktop snapshot exists.

Installing this release preserves the TV's existing pairing and private Worker setup. Reopen Companion after updating.
Stremio source import and the choice of home catalogue are separate settings; the update honours the configured home.
No live physical-TV verification has been performed for this release.
